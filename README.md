`main.py` writes one line — a single original joke about office life, under 200 characters — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, `/output` in the grader).

The joke: a reply-all thread about being removed from the thread, which only grows longer because everyone in it is asking to be removed.
